# Phone version

Status: ✅ Live (21 Oct 2026) · part of [[emet HQ (dashboard)]]

The whole dashboard works on phones; the computer version is unchanged (every phone style applies only under 640px).
- Nothing runs off the right edge; the page never scrolls sideways.
- Bottom tab bar: Today · Board · My team · Base camp · More.
- Your week / My week = small day buttons + a short list for the chosen day.
- Big decorative pictures hidden on phones; compact headers and number cards.
- Finance payment cards 2×2; Team = name + status list; profile numbers in one row; notifications full width and solid.
- Pop-up forms open as bottom sheets above everything.
