# My Projects

Status: ✅ Live · part of [[emet HQ (dashboard)]]

- Only leaders create projects and add people (Team Leader → All projects → New project); Finance can edit budget/status and tag sales.
- You see only the projects you're in: Base camp → My Projects and your profile.
- Project page tabs: Overview · Money (from [[Finance tab]]) · Tasks (leaders add, members move and tick) · Leads (saved from [[Scout (lead finder)]]) · Links · Files · Updates. Project icon photo.
- Migrations 0027–0030.
- **Leads** (27 Oct): self-found places + Scout leads, visited / result (yes, maybe, no) / note, filter Not visited · Visited · All; a visit can add +1 Customer Visit point
- **Customers** (4 Nov): customers we already talked to, with tap-to-call phone numbers; any project member adds them
- **Invite Ollin** (4 Nov): emet members of a project make an invite link (`/join/<code>`, copied to send on WhatsApp). The Ollin person types name + Gmail, gets a login email, and joins only that project as a guest. Guests see their projects and the people in them, nothing else in emet. Delete a link to stop it working. Migrations 0050–0051
