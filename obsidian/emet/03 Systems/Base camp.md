# Base camp

Status: ✅ Live · part of [[emet HQ (dashboard)]]

Each member's **private** area — nobody else can read it, admins included (database-enforced).
- **My week** (3 priorities, weekly reflection, everything due), **focus timer**, week board, activity %
- **Agenda** (own plans + due cards), **Reminders** (private)
- **Docs** — shareable read-only, download Word/PDF/Markdown
- **🎙 Note-taker:** Docs → Record turns a class/meeting into a dated doc (key points, decisions, action items + transcript). Whisper large-v3 via each member's **own free Groq key** (~8 h/day audio); keys encrypted; fallback = browser transcription. **Redo transcript** re-reads saved audio (kept 60 days)
- **Idea wall** — sticky notes, send to board
- **Password vault** — encrypted on the device with a personal passphrase (forgotten = unrecoverable). Shared team passwords belong in a shared manager (e.g. Bitwarden)
- **27 Oct:** "Docs" renamed **Recorded meetings**; My week opens on **Today** (Week still one tap away); recordings without notes get a **Write the summary** button (shared ones save your own copy); long recordings now get notes part by part, so the free Groq limit no longer loses them
